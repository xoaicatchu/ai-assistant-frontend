🔌 Hướng dẫn tích hợp MCP Kết nối MCP server qua gateway và dùng tool trong cuộc trò chuyện ⌄

Customize hiện không chạy MCP server trực tiếp trong trình duyệt. MCP cần được cấu hình ở 9Router/backend, sau đó gateway chuyển tool call tới model.

  1. Chạy MCP server của bạn bằng stdio hoặc HTTP/SSE ở 9Router.
  2. Đăng ký server và các tool trong 9Router, rồi expose gateway ở endpoint OpenAI-compatible.
  3. Nhập Base URL, API key và route model của gateway ở các ô phía trên.
  4. Chọn model có badge Tool call, rồi gửi câu hỏi cần dùng tool.
